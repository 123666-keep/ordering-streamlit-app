# 该订多少 — 便利店智能订货系统（Streamlit）

面向便利店场景的智能订货演示系统：基于加权移动平均的需求预测、报童模型三档订货建议、
现金约束下的优先级预算分配，以及缺货 / 报损 / 需求波动规则引擎复盘。

## 功能

- 登录鉴权（店主 / 店员双角色，店员隐藏进价与毛利）
- 今日看板：临期库存提醒、待确认售罄、高波动品类待办
- 订货：预测 ± 波动、三档建议（少订一成 / 按预测订 / 多订两成）、预算分配与优先级
- 记录：到货登记、售罄时刻标记、报损登记、售罄时刻散点图
- 复盘：预测 vs 实际折线图、误差柱状图、规则引擎经营建议、CSV 导出
- 设置：商品档案、重建演示数据

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

数据库 `data/shop.db` 首次启动自动建库并写入演示种子数据。

## 部署说明

本项目通过 GitHub 仓库部署到 Streamlit Community Cloud。
注意：Community Cloud 的本地文件系统是临时的，重启 / 重新部署后数据库会重置并重新生成演示数据。
